# 小王回复维护说明

公开版默认免配置本地情景回复。`dist/wang-dialogue.js`维护原创角色口吻、主题回复和用户明确提供的记忆；`dist/wang-chat-runtime.js`负责短延迟、合并连续消息、草稿保留、未读、暂停和刷新恢复。当前未接入模型，回复覆盖常见日常话题，复杂问题可能只能追问；不要向访客宣传为AI自由聊天或真人回复。

存档沿用 `xiaosheng-phone-v1`。新字段默认值兼容旧数据，聊天和偏好只保存在玩家当前浏览器，不跨设备共享。支持开发者入口位于微信「我」和手机「设置」页面，不在小王聊天中弹出。音频/照片导入维持原行为，其他联系人不会自动回应。

## 可选真实模型接口

仓库附带 `server/wang-chat.mjs`，未部署、未配置模型，真实上游调用尚未验收。需要项目所有者在独立Node 20+后端的私密环境变量中设置：

- `LLM_API_KEY`：模型服务密钥，绝不能写入GitHub或浏览器代码。
- `LLM_CHAT_URL`：完整HTTPS聊天接口URL，需兼容OpenAI式chat completions请求/返回格式。
- `LLM_MODEL`：该服务可用模型的精确名称。
- `ALLOWED_ORIGINS`：允许的网页Origin，以逗号分隔；默认包含现有GitHub Pages和原公开站点。
- `PORT`：可选，默认8787。

运行 `node server/wang-chat.mjs`，让部署平台提供HTTPS。`GET /health`仅报告是否配置齐全，不证明模型实际可用。`POST /chat`接收最后16条文字历史，由服务端加入角色设定。请求不包含图片/音频，不接受客户端system消息。

后端部署验收后，在网页加载 `wang-chat-runtime.js` 前设置 `window.WANG_CHAT_ENDPOINT` 为该HTTPS后端的 `/chat` 完整地址。不要写入任何密钥。只有收到有效模型结果，聊天详情才显示AI对话；超时或错误自动降级为本地情景回复。离线版未设置接口时始终本地运行。

当前后端仅有基础Origin检查、正文长度限制和内存限流。公开付费模型服务还需配置供应商消费上限和部署平台请求配额；Origin不是身份认证，反向代理后的共享IP限流也需由平台处理。上线前实际测试中文回复、故障降级和费用限制，并明确告知访客文字历史会发到配置的模型后端。当前静态站没有这项传输。
