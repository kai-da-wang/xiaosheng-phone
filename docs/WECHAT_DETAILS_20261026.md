# 微信聊天详情页参考与实现

使用 iPhone 微信常见的完整信息页结构，单聊标题“聊天详情”，群聊标题“聊天信息(人数)”。版本可能影响文案与设置顺序；没有宣称逐像素复制某个最新发行版本。

## 已实现

- 全页导航、灰底白色分组、细分隔线、成员网格、iOS绿色开关；单聊头像旁为加号，群聊展示全部现有成员。
- 按会话存储免打扰、置顶、背景。免打扰抑制消息提示音、横幅及桌面未读计数，聊天列表保留小红点；来电开关仍独立。
- 群名、备注、自己的群昵称、显示成员昵称、保存群聊到通讯录。普通成员只能查看群公告；自己建立的本机群可编辑公告。
- 查找实际静态/动态记录、文字搜索、图片/语音类别、群成员筛选，以及跳回原消息并高亮。不会把相册自动展示成微信图片合集。
- 加号选择联系人；单聊会建立独立的本机群，已有群会加入所选联系人。新群的对话独立保存，不冒用原单聊回复引擎。
- 清空记录有确认，取消该会话待回复队列，隐藏该会话原故事并清除动态记录，照片应用原图保留。退出群聊保留已有记录，停止群内回复并关闭输入。
- 原有角色回复和记忆设置移至手机“设置 → 角色对话设置”。

## 能力边界

这是模拟手机。群二维码入口说明没有真实微信群二维码，投诉页明确只保存本机反馈；不会发送微信消息、邀请或投诉。
